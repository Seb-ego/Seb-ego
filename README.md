# Hi, I'm Sébastien Ego 👋

I build [Shadowban Radar](https://shadowbanradar.com), a free Twitter (X) shadowban test.

Shadowban Radar runs a free Twitter (X) shadowban test on any public account, with no login or password: 4 checks (search suggestion ban, search ban, ghost ban, reply deboosting), a verdict, and a confidence level for each check.
